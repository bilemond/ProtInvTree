# Licensing status

The authors have deferred choosing a license for the ProtInvTree research code.
No new license grant for that code is made by this preparation of the repository.
The authors must decide and add the research-code license before advertising a
fully licensed open-source release.

The `esm/` directory retains the upstream ESM licensing arrangements recorded in
[third_party/ESM_LICENSE.md](third_party/ESM_LICENSE.md). This file does not replace
or override them. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for provenance
and model-weight references. Model weights are downloaded separately.
